# 💰 Aile Bütçesi (Family Budget App)

Modern, güvenli ve kullanımı kolay açık kaynak kişisel ve aile bütçesi yönetim uygulaması. Flutter ve Firebase ile geliştirilmiştir.

---

### ✨ Öne Çıkan Özellikler

* **👨‍👩‍👧‍👦 Aile Planı & Ortak Bütçe:** 6 haneli davet kodu ile ailenizi bağlayın, harcamalarınızı tek havuzda kimin yaptığını görerek yönetin.
* **📊 Görsel Analizler & Grafikler:** Harcama dağılımı (Pie Chart) ve karşılaştırma (Bar Chart) ile finansal durumunuzu anlık görün.
* **🎯 Birikim Hedefleri:** Hayalinizdeki hedefler için birikim ekleyin, ilerleme çubuğuyla takip edin.
* **💳 Banka & Borç Takibi:** Taksitli ve vadeli borçlarınızı kaydedin, yaklaşan ödemeleri kaçırmayın.
* **🔁 Abonelik Yönetimi:** Haftalık, aylık veya yıllık aboneliklerinizi (Netflix, Spotify vb.) tek listede görün.
* **📄 PDF Finansal Rapor:** Harcama ve gelir özetinizi tek tıkla PDF raporuna dönüştürün ve yazdırın.
* **🎨 Tema ve Dil Desteği:** 7 farklı lüks renk teması, Türkçe ve İngilizce tam dil desteği.
* **⚡ Hızlı & Çevrimdışı Çalışma:** Yerel önbellekleme sayesinde internetsiz ortamda bile anında açılır.

### 🛠️ Geliştiriciler İçin Kurulum

Projeyi yerel ortamınızda çalıştırmak için:

1. Depoyu klonlayın:
   ```bash
   git clone https://github.com/KULLANICI_ADIN/family_budget_app.git
   cd family_budget_app
   ```
2. Bağımlılıkları yükleyin:
   ```bash
   flutter pub get
   ```
3. Firebase yapılandırmanızı ekleyin:
   * `android/app/google-services.json.example` dosyasını kopyalayarak `android/app/google-services.json` adıyla oluşturun ve kendi Firebase proje bilgilerinizi girin.
4. Uygulamayı çalıştırın:
   ```bash
   flutter run
   ```
